# Phase 3 — Services Ecosystem

## Structure

Section `#services` with four category cards driven by Neon:

1. THINK
2. CREATE
3. BUILD
4. GROW

Category **labels / framing** come from `SERVICE_CATEGORY_META`.  
Service **names and summaries** come only from `findActiveServices()`.

## Project proof

When a published project links to a service in the category, one real preview is shown with link to `/work/[slug]`.

When none exist: decorative category composition (not attributed client work).

## Empty category

Categories with zero active services are omitted.

## Transition

Work → services bridge (“We prove the work → We explain the system”).  
Services closing statement points to future `#packages` without pricing UI.
