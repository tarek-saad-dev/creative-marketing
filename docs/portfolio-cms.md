# CMS-first portfolio
Create a draft in /admin/projects, add title, industry and summary, save, upload image/video or attach a URL, choose an uploaded image as cover, set alt text, order and featured, preview then publish. Homepage galleries use published data; /work is the complete project index with search and industry filters. Video thumbnails use an explicit image, a Cloudinary still, or the project cover. Broken image/video loads have an accessible fallback. Existing media remains unchanged; no migration. Review actual media delivery, dashboard credentials and Cloudinary configuration, draft preview and publish on staging. Before/after uses the existing explicit caption markers. Build and real-device QA still required. No claim of zero defects.
